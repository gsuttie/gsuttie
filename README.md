#Gregor Suttie

Hiya, I'm Gregor 👋 (aka Azure Greg)

Senior Azure Architect at Intercept · Microsoft Azure MVP · Glasgow, Scotland 🏴󠁧󠁢󠁳󠁣󠁴󠁿

I design and run Azure platforms for a living, and I spend the rest of my time trying to make Azure easier for everyone else - through open source, community events, and tools that save people from reading release notes. Fundamentals first; shiny things second.
